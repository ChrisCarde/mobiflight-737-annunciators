737 Annunciator Panels
======================

What is in this download
------------------------

  Community\                    For MobiFlight Connector. Copy the Annunciator folder inside it
                                into %LOCALAPPDATA%\MobiFlight\MobiFlight Connector\Community
  Start-MobiFlight-E32R32P.bat  Starts the Connector for the 3.2-inch board (not needed for the
                                3.5-inch one)
  Source\                       The project's source code, including the profiles and the tool
                                that makes them for your own board
  Firmware\                     Full flash images, for flashing a board by hand. Most people
                                install the firmware from the browser installer instead
  Licenses\, LICENSE,           The licences of this project and of the software in the firmware
  THIRD-PARTY-NOTICES.md
