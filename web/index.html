Installs the firmware on either display board, straight from this page. It works out which board is plugged in.

3.2″ LCDWIKI E32R32P or 3.5″ Caturda C3248W535. Close MobiFlight Connector first.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a desktop computer.

The installer only works over a secure connection. Open it from its published address.

Step by step

  1. Close MobiFlight Connector.

    While it runs it holds the board's port, and the installer cannot open it.

  2. Plug the board into this computer.

    For the 3.2″ board use a USB-A to USB-C cable. A C-to-C cable does not work with that board.

  3. Click Install firmware and choose the board's port.

    BoardListed as
    3.2″USB-SERIAL CH340 or USB Serial
    3.5″USB JTAG/serial debug unit

  4. Choose Install, then decide about erasing.

    First install: tick Erase device. It clears out the demo the board shipped with. Updating: leave it unticked, and the board keeps its panel setup and its touch calibration.

  5. Wait for “Installation complete”, then unplug the board and plug it back in.

    The screen stays dark until MobiFlight sends it something. That is normal. Carry on with step 3 of the setup guide.

If it does not connect

  • The board is not in the list. Try another cable; some carry power only. On the 3.5″ board, unplug it, hold its BOOT button while you plug it back in, and try again.
  • “Failed to initialize”. Check that MobiFlight Connector is closed. On the 3.5″ board, use the BOOT button as above, then click Install firmware again.
  • Still stuck? The setup guide explains how to flash the board by hand, or open an issue.
